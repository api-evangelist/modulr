## API Reference
- [Create account by customer](https://modulr.readme.io/reference/createaccount.md): Creates an account for a particular customer using the customer’s ID as a reference
- [Get an account](https://modulr.readme.io/reference/getaccount.md): Retrieve details of a particular account using its ID as a reference
- [Get accounts by customer](https://modulr.readme.io/reference/getaccountsbycustomer.md): Get details of accounts belonging to a particular customer using the customer’s ID as a reference
- [Get accounts using filter](https://modulr.readme.io/reference/getaccounts.md): Gives the ability to find accounts and get their details using filters
- [Edit an account](https://modulr.readme.io/reference/editaccount.md): Edit details of a particular account using its ID as a reference Currently editable fields:   1. for accounts of all customer types, externalReference can be edited   2. for accounts of PCM_INDIVIDUAL & PCM_BUSINESS customer types, name can additionally be edited
- [Set the secured funding limit for an account](https://modulr.readme.io/reference/updatesecuredfundinglimit.md)
- [Block a specific account](https://modulr.readme.io/reference/blockaccount.md): Using a unique reference (account ID) you can block an account
- [Unblock a specific account](https://modulr.readme.io/reference/unblockaccount.md): Using a unique reference (account ID) you can unblock an account
- [Close an account](https://modulr.readme.io/reference/closeaccount.md): Accounts with a zero balance can be closed. The account must have a status of ACTIVE or CLIENT_BLOCKED.
- [Create a card authorisation](https://modulr.readme.io/reference/createauthorisation.md): Create an authorisation for a card
- [Settle the full or partial card authorisation](https://modulr.readme.io/reference/settleauthorisation.md): Settle the full card authorisation or supply an optional settlementAmount for partial settlement.
- [Reverse the card authorisation](https://modulr.readme.io/reference/reverseauthorisation.md): Simulate a reversal of an authorization for a card
- [Perform an account status inquiry](https://modulr.readme.io/reference/performaccountstatusinquiry.md): Check whether a card is eligible for transactions without reserving funds
- [Create a settlement without prior authorisation](https://modulr.readme.io/reference/createsettlement.md): Submit a settlement directly to the reconciliation pipeline without a prior authorisation
- [Create a card refund](https://modulr.readme.io/reference/refund.md): Simulate a standalone refund (credit) for a card, producing a REFUND activity
- [Simulate an original credit](https://modulr.readme.io/reference/createoriginalcredit.md): Submit card activity of type original credit
- [Reverse an original credit](https://modulr.readme.io/reference/reverseoriginalcredit.md): Reverse a previously applied original credit, producing an ORIGINAL_CREDIT_REVERSAL activity
- [Create a standalone chargeback](https://modulr.readme.io/reference/createchargeback.md): Simulate a standalone chargeback for a card.
- [Chargeback an existing settlement](https://modulr.readme.io/reference/createchargebackforsettlement.md): Simulate a chargeback of an existing settlement activity.
- [Create an offline transaction](https://modulr.readme.io/reference/createofflinetransaction.md): Simulate an offline transaction for a card
- [Reverse a chargeback](https://modulr.readme.io/reference/createchargebackreversal.md): Simulate a chargeback reversal for an existing CHARGEBACK activity, producing a CHARGEBACK_REVERSAL activity.
- [Simulate a card expiry](https://modulr.readme.io/reference/expirecard.md): Simulate the GPS CARD_EXPIRY message, transitioning the card status to EXPIRED in card-service
- [Reverse a credit authorisation](https://modulr.readme.io/reference/reversecreditauthorisation.md): Reverse a pending credit authorisation, producing a CREDIT_AUTH_REV activity
- [Simulate a credit authorisation](https://modulr.readme.io/reference/createcreditauthorisation.md): Submit card activity of type credit authorisation
- [Resettlement of a chargeback](https://modulr.readme.io/reference/createresettlement.md): Simulate a resettlement (second presentment) for an existing CHARGEBACK activity, producing a RESETTLEMENT activity.
- [Unbind a device from a card token](https://modulr.readme.io/reference/unbinddevice.md): Simulate the removal of a device binding from a card token, marking the device as DELETED within the token record in card-service
- [Get tasks](https://modulr.readme.io/reference/getasynctasks.md): View the details of card tasks.  Ordered by createdDate, with the newest entries appearing first
- [Get a card task](https://modulr.readme.io/reference/getasynctask.md): Retrieve the card task. If the task is complete, the resource URL will be provided to allow client to fetch the completed resource.
- [Get physical card create tasks by account](https://modulr.readme.io/reference/getcreatephysicalcardasynctasksbyaccount.md): View the details of create physical card tasks by account.  Ordered by createdDate, with the newest entries appearing first
